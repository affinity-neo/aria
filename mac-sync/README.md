# ARIA ↔ Apple 미리 알림 양방향 동기화

맥에서 실행되는 도우미가 Apple 미리 알림의 **정확히 이름이 `ARIA`인 목록만** 감시합니다. ARIA 웹 앱의 빠른 메모와 양쪽으로 추가·수정·완료·삭제를 동기화합니다.

## 처음 연결

1. ARIA 웹사이트를 열고 빠른 메모 → ** 미리 알림 연결**을 누릅니다.
2. Firebase 규칙은 기존 규칙을 보존해 병합합니다. 기존 규칙을 통째로 덮어쓰지 마세요.
3. 화면의 요청 URL을 복사합니다.
4. 최신 `mac-sync` 폴더에서 `run.command`를 실행합니다. Finder에서 이동 → 유틸리티 → 터미널을 열고 `bash `를 입력한 뒤 `run.command`를 터미널에 끌어다 놓고 Enter를 누르면 됩니다.
5. 처음 실행할 때 Terminal의 미리 알림 접근을 허용하고, 요청 URL을 붙여넣습니다.
6. ARIA 화면에서 **양방향 동기화 시작**을 누릅니다.

## 동기화 동작

- Apple의 ARIA 목록에 새 항목을 추가하면 ARIA 빠른 메모에 나타납니다.
- ARIA 빠른 메모에서 새 항목을 만들면 Apple의 ARIA 목록에 생성됩니다.
- 제목·메모·완료 상태 변경은 양쪽에 반영됩니다.
- 어느 쪽에서 삭제해도 반대쪽에서 삭제됩니다. ARIA에서 업무로 옮기는 경우에도 연결된 Apple 미리 알림을 삭제합니다.
- Apple의 다른 목록은 읽거나 수정하지 않습니다.
- 삭제는 동기화용 삭제 표시(tombstone)로 전파됩니다. Apple에서 ARIA 목록 밖으로 이동하거나 목록에서 삭제한 항목도 다음 동기화 때 ARIA에서 제거됩니다.
- 맥이 켜져 있고 도우미가 실행 중이어야 합니다. 확인 간격은 약 5초입니다.
- 종료하려면 터미널에서 Control+C를 누릅니다.

## 주의

- 양방향 동기화이므로 삭제는 양쪽에 반영됩니다. 필요한 항목을 실수로 삭제하지 않도록 테스트 항목으로 먼저 확인하세요.
- 맥 도우미가 실행되지 않는 동안에도 ARIA 웹 앱은 변경 사항을 Firebase에 기록하며, 도우미가 다시 실행되면 Apple 쪽에 반영합니다.
- 연결 URL에는 비밀 토큰이 포함됩니다. 다른 사람과 공유하지 마세요.
- 설정 파일은 `~/.config/aria-reminders/config.json`, 연결 매핑은 `~/.config/aria-reminders/two-way-state.json`에 저장됩니다.
- IFTTT 자동화가 남아 있다면 중복 작업을 막기 위해 꺼 두세요.

## 문제 해결

- 미리 알림 권한: macOS 시스템 설정 → 개인정보 보호 및 보안 → 미리 알림에서 Terminal을 허용합니다.
- 목록을 찾지 못함: Apple 미리 알림 앱에서 목록 이름이 정확히 `ARIA`인지 확인합니다.
- Firebase 오류: ARIA 연결 화면의 요청 URL과 기존 규칙에 병합한 Firebase 규칙을 확인합니다.
