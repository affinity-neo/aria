# ARIA ↔ Apple 미리 알림 (Mac 동기화 도우미)

이 도구는 맥에서 Apple 미리 알림의 `ARIA` 목록을 10초마다 확인하고, 아직 전송하지 않은 미완료 항목을 ARIA의 Firebase 수신 주소로 보냅니다. 방향은 **Apple 미리 알림 → ARIA 빠른 메모** 단방향입니다.

## 시작하기

1. 맥에서 Safari/Chrome으로 https://affinity-neo.github.io/aria/ 를 엽니다.
2. **빠른 메모**에서 ** 미리 알림 연결**을 누릅니다.
3. Firebase 규칙을 아직 적용하지 않았다면 화면에 표시된 규칙을 확인하고 게시합니다. 이미 IFTTT 연결용 규칙을 적용했다면 다시 덮어쓰지 마세요.
4. 화면의 **요청 URL**을 복사합니다.
5. Finder에서 `mac-sync` 폴더를 열고, 상단 메뉴 **이동 → 유틸리티 → 터미널**을 실행합니다. 터미널에 `bash `까지 입력한 뒤 Finder의 `run.command` 파일을 터미널 창으로 끌어다 놓고 Enter를 누릅니다.
6. 처음 실행할 때 macOS가 Terminal의 미리 알림 접근을 요청하면 허용합니다. 터미널에 요청 URL을 붙여넣고 Enter를 누릅니다.
7. Apple 미리 알림의 **ARIA** 목록에 미완료 항목을 추가합니다. 보통 10초 안에 터미널에 전송 로그가 나타나고, ARIA 빠른 메모에 반영됩니다.

## 중요한 점

- 첫 실행 때 ARIA 목록에 이미 들어 있는 **모든 미완료 항목**도 한 번 전송됩니다. 기존 항목을 원치 않으면 실행 전에 ARIA 목록을 비우거나 별도 테스트 목록을 사용하세요.
- 이전에 만든 IFTTT 자동화가 켜져 있다면 중복 등록을 막기 위해 먼저 끄세요.
- 이 프로그램은 맥이 켜져 있고 실행 중일 때만 동기화합니다. 터미널 창을 닫거나 Control+C를 누르면 중지됩니다.
- 중복 전송을 막기 위해 전송한 항목 식별자를 `~/.config/aria-reminders/sent-identifiers.json`에 보관합니다.
- Firebase 요청 URL에는 비밀 토큰이 포함되어 있습니다. 공유하거나 공개 저장소에 올리지 마세요.
- 현재 버전은 새 항목을 빠른 메모로 가져오는 단방향 테스트 버전입니다. 수정·완료 상태의 양방향 동기화는 하지 않습니다.

## 문제 해결

- 권한을 거부했다면 macOS **시스템 설정 → 개인정보 보호 및 보안 → 미리 알림**에서 Terminal을 허용한 뒤 다시 실행합니다.
- 목록을 찾지 못하면 미리 알림 앱에서 목록 이름이 정확히 `ARIA`인지, iCloud 동기화가 완료됐는지 확인합니다.
- Firebase 응답 오류가 나면 ARIA 연결 화면의 요청 URL과 Firebase Realtime Database 규칙을 확인합니다.
